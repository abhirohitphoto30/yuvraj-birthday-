# Yuvraj Birthday Website 🎂

A responsive birthday surprise website built with plain HTML, CSS and JavaScript. No build step or framework required.

## Run locally
Open `index.html` in your browser, or run `npx serve .`.

## Deploy to Vercel
1. Upload the contents of this folder to a GitHub repository.
2. Import the repository at https://vercel.com/new
3. Framework Preset: **Other**
4. Build Command: leave empty
5. Output Directory: leave empty (repository root)
6. Deploy.

All assets (`style.css`, `script.js`, and `photos/`) are at the repository root so the paths work on Vercel.

## Personalize
- Replace/add images in `photos/` and update the `photos` array in `script.js`.
- Edit text in `index.html`.
- Countdown is set for 14 November 2026, India time.
